# 0GPulse – Wallet Tracker & Explorer for 0G-Testnet-Galileo

0GPulse is a web application that lets you analyze wallet activity, track achievements, and explore the 0G-Testnet-Galileo network.

## Main Features

- **Wallet Search**: Look up any wallet on 0G-Testnet-Galileo and see detailed statistics.
- **Overview & Stats**: View balances (native and tokens), transaction history, daily activity, and more.
- **Achievements**: Unlock and display wallet milestones and ranks.
- **Token Holdings**: See balances for all tokens held in the wallet.
- **Contract Interactions**: Track which contracts your wallet interacts with.
- **Leaderboard**: Compare wallet activity and achievements with others.
- **Charts & Analytics**: Visualize wallet activity over time.
- **Built for Fun**: This site is built for the Fogo Testnet and is NOT incentivized—just a fun way to track your wallet!

## Usage

Visit the site, enter a 0G-Testnet-Galileo wallet address, and instantly see an interactive dashboard of stats, tokens, transactions, achievements, and more.
